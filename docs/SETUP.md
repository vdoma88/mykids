# Установка: с нуля до работающего

Нужны: одна машина под сервер (подойдёт домашний мини-ПК, NAS или тот же
компьютер родителя) и компьютер ребёнка под Windows 10 или 11.

Весь порядок — примерно на полчаса, из них двадцать минут уйдёт на
обдумывание лимитов и курса обмена.

---

## 1. Сервер

Данные об активности ребёнка не уходят в чужое облако: всё остаётся на этой
машине.

```bash
git clone https://github.com/vdoma88/mykids.git
cd mykids
cp deploy/.env.example deploy/.env
```

В `deploy/.env` обязательно смените `POSTGRES_PASSWORD` и `SESSION_SECRET`.
Значения из примера — это не «пока сойдёт», это открытая дверь в журнал
активности вашего ребёнка.

```bash
docker compose -f deploy/docker-compose.yml up -d
```

Проверка: откройте `http://адрес-этой-машины:3000/`. Должна открыться
страница входа. Если открывается только с самой машины — проверьте, что порт
3000 не закрыт брандмауэром: компьютер ребёнка должен до него достучаться.

> Сервер доступен по HTTP, без шифрования. В домашней сети этого достаточно.
> Выставлять порт 3000 в интернет **не нужно**: агенту хватает локальной сети,
> а токен устройства по открытому каналу через интернет ходить не должен.

## 2. Семья, ребёнок, правила

В открывшейся админке:

1. **Зарегистрируйтесь.** Первый аккаунт становится владельцем семьи.
   Сразу включите второй фактор — пароль от админки это пароль от экранного
   времени, и подобрать его ребёнок попробует.
2. **Заведите ребёнка** и задайте политику: дневной лимит по дням недели,
   перенос остатка, окна расписания (школа, отбой), курс обмена кредитов в
   минуты и потолки.
3. **Назначьте пакеты заданий** — то, чем ребёнок будет зарабатывать. Без
   этого шага заработать кредиты ему негде, и остаётся только просить у вас.

Курс обмена сразу «на глаз» не выставляется. На странице ребёнка есть
симулятор: он считает теми же функциями, что и сервер, и показывает, во что
превращается дневной заработок. Посмотрите на цифру, прежде чем соглашаться.

## 3. Учётная запись ребёнка на его компьютере

**Единственное условие, без которого всё остальное бессмысленно:** учётная
запись ребёнка должна быть обычной, без прав администратора. Ребёнок с правами
администратора останавливает службу из оснастки, и агент не помешает ему ничем.

Проверить: «Параметры» → «Учётные записи» → «Семья и другие пользователи».
Под именем ребёнка должно быть написано «Обычный доступ», а не
«Администратор». Если написано «Администратор» — «Изменить тип учётной
записи» → «Обычный пользователь».

Родительская учётная запись при этом остаётся администратором: из неё вы
ставите агент и правите настройки.

## 4. Агент на компьютере ребёнка

Скачайте `mykids-agent.exe` и `install-windows.ps1` со [страницы
релиза](https://github.com/vdoma88/mykids/releases) и положите рядом.

В админке, на странице ребёнка, нажмите **«Выдать токен»** — он показывается
один раз.

Из учётной записи **родителя**, в PowerShell **от имени администратора**:

```powershell
powershell -ExecutionPolicy Bypass -File install-windows.ps1 `
    -Server http://адрес-сервера:3000 `
    -Token  <токен устройства> `
    -ChildUser <имя учётной записи ребёнка>
```

Скрипт проверит права учётной записи ребёнка, скопирует агент в
`C:\Program Files\MyKids`, заведёт каталог данных в `C:\ProgramData\MyKids`,
закроет к нему доступ всем, кроме службы и администраторов, привяжет
устройство и зарегистрирует службу с автозапуском.

Каталог данных — машинный, а не в профиле, и это не мелочь: служба работает
под `LocalSystem`, а привязку делаете вы из своей учётной записи. В профилях
это были бы два разных каталога, и служба молча работала бы автономно.

## 5. Проверка

```powershell
& 'C:\Program Files\MyKids\mykids-agent.exe' -data C:\ProgramData\MyKids status
```

Должно быть видно активное окно, остаток времени и строку «связь с сервером»:
когда прошёл обмен, откуда взята политика, сколько минут ждёт отправки.

Затем войдите в учётную запись ребёнка. Помощника служба поднимет сама —
запускать руками ничего не надо. За несколько минут до конца лимита внизу
справа появится полоса «Осталось N минут · Сохранись», а когда время кончится
— экран закроется с объяснением, сколько есть кредитов и где задания.

В админке, на странице ребёнка, к этому времени появятся израсходованные
минуты.

## Что ребёнок может, а что нет

Честно, без обещаний:

| Попытка | Что будет |
|---|---|
| Закрыть помощника | Служба поднимет его обратно; молчание помощника считается расходом, а не отдыхом |
| Снимать помощника раз за разом | Пять раз за десять минут — и родителю уходит событие |
| Остановить службу из своей учётки | Не хватит прав |
| Убить агент целиком (с правами администратора) | Пропущенное время спишется при следующем запуске, родитель получит событие |
| Перевести системные часы | Сдвиг замечается и гасится поправкой, родитель получает событие |
| Править `policy.json` | Ничего не даст: правила берутся из кэша, полученного с сервера |
| Подменить помощника своим | Ложь о простое ловится на противоречии: без ввода активное окно не меняется |
| Удалить каталог данных | Нет прав; а пропуск всё равно оплачивается при следующем запуске |

Чего агент **не** умеет: он не помешает ребёнку с правами администратора, не
работает на втором компьютере без второй привязки и не следит за тем, что
именно ребёнок делает на экране — только за тем, какое окно активно и сколько
времени прошло.

## Задания с закрытого экрана

Когда время кончилось, экран закрыт целиком, включая браузер. Задания в этот
момент открываются с другого устройства — с телефона или планшета, по тому же
адресу `/child`.

Открыть их на самом заблокированном компьютере можно, добавив браузер в
`alwaysAllowed` в политике, но надо понимать цену: браузер, внесённый в белый
список, не блокируется и не считается **никогда**, то есть ребёнок получает
неограниченный интернет. Это ваш выбор, и по умолчанию он не сделан за вас.
Задания и магазин в отдельном окне агента — в планах (`docs/ROADMAP.md`).

## Обновление и удаление

Обновление — замена `mykids-agent.exe` при остановленной службе:

```powershell
& 'C:\Program Files\MyKids\mykids-agent.exe' -data C:\ProgramData\MyKids service stop
Copy-Item .\mykids-agent.exe 'C:\Program Files\MyKids\mykids-agent.exe' -Force
& 'C:\Program Files\MyKids\mykids-agent.exe' -data C:\ProgramData\MyKids service start
```

Удаление:

```powershell
& 'C:\Program Files\MyKids\mykids-agent.exe' -data C:\ProgramData\MyKids service stop
& 'C:\Program Files\MyKids\mykids-agent.exe' -data C:\ProgramData\MyKids service uninstall
Remove-Item -Recurse 'C:\Program Files\MyKids', 'C:\ProgramData\MyKids'
```

Сервер остаётся: журнал и балансы никуда не денутся.

## Если что-то не работает

| Симптом | Где смотреть |
|---|---|
| Админка не открывается | `docker compose -f deploy/docker-compose.yml logs api` |
| `status` говорит «автономный режим» | Привязка делалась не тем `-data` или токен отозван |
| Минуты не доходят до сервера | `status` покажет, сколько ждёт в очереди; очередь переживает офлайн и уйдёт сама |
| Экран не закрывается | Проверьте, что ребёнок вошёл в свою учётную запись, а не в родительскую |
| Служба не стартует | Журнал событий Windows, источник `MyKidsAgent` |
