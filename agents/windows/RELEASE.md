# mykids-agent 0.3.0 — Windows x64

Один файл, рантайм ставить не нужно. Работает и автономно, и с сервером семьи.

## Установка

Положите `mykids-agent.exe` в любую папку на компьютере ребёнка, например `C:\MyKids`.

Проверьте контрольную сумму — она должна совпасть с `mykids-agent.exe.sha256`:

```
certutil -hashfile mykids-agent.exe SHA256
```

## Привязка к серверу

Токен выдаёт админка на странице ребёнка кнопкой «Выдать токен». Он показывается
один раз.

```
mykids-agent.exe enroll -server https://адрес-сервера -token <токен>
```

Без привязки агент работает по локальному файлу правил — это режим для проверки,
а не для боя.

## Порядок проверки

Три команды идут в этом порядке намеренно: сначала убедитесь, что агент видит
нужное, и только потом отдавайте ему право закрывать экран.

```
mykids-agent.exe status    один замер: активное окно, простой, остаток, связь
mykids-agent.exe watch     учёт времени без блокировки — оставьте на день
mykids-agent.exe run       учёт с блокировкой экрана
```

Начните со `status`. Он должен показать имя активного окна. Если вместо него
ошибка — сообщите её, дальше идти смысла нет.

## Обязательное условие

**Учётная запись ребёнка должна быть обычной, без прав администратора.** Это не
рекомендация: локальный администратор закроет агент из диспетчера задач.

Снять агента и так невыгодно — пропущенное время списывается при следующем
запуске, а родитель получает событие. Но пока агент не оформлен службой Windows,
одни только права решают, сможет ли ребёнок его остановить.

## Что нового в 0.3.0

- **Правила приходят с сервера.** Локальный `policy.json` лежит в профиле ребёнка
  и доступен ему на запись, поэтому после привязки он перестаёт что-либо значить:
  агент работает по серверной копии, в том числе без связи.
- **Расход уходит на сервер** и переживает офлайн и перезапуск; повторная отправка
  не удваивает списание.
- **Перевод часов ловится и гасится.** Исправленное время идёт ровно, так что
  перевести часы на три часа назад и уйти из окна «отбой» не получится.
- **Снятие агента оплачивается.** Пропущенное время списывается при следующем
  запуске, ограничено дневной выдачей, и родитель видит точную величину.
- **Сообщения родителю ждут в файле состояния.** Выдернуть сеть, снять агента и
  вернуть сеть обратно, чтобы скрыть след, не выйдет.

## Чего пока нет

Службы Windows, трея, магазина и заданий прямо в агенте, защиты от снятия,
установщика и подписи кода. Windows будет предупреждать о неизвестном издателе —
это ожидаемо для неподписанного файла.

Отличить сбой питания от снятия агента агент не умеет. Если компьютер просто
выключился по питанию, верните время ручной корректировкой на ту величину, которая
указана в событии.
