# MyKids — Windows x64

Ребёнок зарабатывает экранное время учебными заданиями. Сервер стоит дома,
данные об активности никуда не уходят.

## Что в релизе

| Файл | Зачем |
|---|---|
| `MyKids-Setup-X.Y.Z.exe` | Установщик для компьютера ребёнка: мастер на русском, обновление поверх, удаление из «Параметров» |
| `sha256.txt` | Контрольная сумма установщика |

Сервер разворачивается из репозитория: `docker compose -f deploy/docker-compose.yml up -d`.

## Что нового в 0.9.0

**Полноценный установщик.** Один файл вместо шести, и установка за один
проход вместо двух.

Раньше было так: MSI раскладывал программы, а привязку и службу делало
отдельное окно, которое ещё надо было найти в меню «Пуск» и запустить правой
кнопкой от имени администратора. Шаг, о котором надо помнить, — это шаг,
который пропустят: программы стоят, служба не зарегистрирована, ребёнок
свободен. Теперь:

- **Мастер на русском, целиком.** Ярлыки тоже: прежний MSI собирался
  инструментом, который молча выбрасывал кириллицу, и подписи были латиницей.
- **Токен проверяется до установки.** Мастер спрашивает сервер, чей это токен,
  и показывает: «это будет компьютер ребёнка „Маша“». Раньше привязка только
  записывала токен в файл — опечатка в адресе, отозванный или чужой токен
  обнаруживались через день, когда в админке не появлялось минут.
- **Учётная запись ребёнка — из списка**, в котором только обычные учётные
  записи этого компьютера. Администратора мастер не примет.
- **Обновление — тот же файл поверх.** Привязка сохраняется, токен заново не
  нужен. Сервер переехал на другой IP — впишите новый адрес, прежний токен
  мастер проверит на нём сам.
- **Ярлык «Задания MyKids» на рабочем столе** — ребёнок находит задания, не
  дожидаясь закрытого экрана.
- **Удаление больше не оставляет закрытый экран.** Прежний деинсталлятор
  снимал службу, но помощник в сессии ребёнка оставался работать — и без
  службы через минуту закрывал экран до перезагрузки. Теперь он закрывается
  вместе со службой. Журнал учёта по желанию удаляется галочкой.
- **Установка без окон** для нескольких машин:
  `MyKids-Setup-X.Y.Z.exe /S /SERVER=... /TOKEN=... /CHILD=...` — с теми же
  проверками и кодом возврата. Заменяет `install-windows.ps1`.

Как обновиться с 0.8: запустите новый установщик поверх. Пакет MSI он удалит
сам (двух записей «MyKids» не будет), привязку подхватит. Сервер в этом
релизе не менялся.

## Что нового в 0.8.1

Снова только сервер; программы для Windows те же.

- **Пароль родителя больше нельзя перебирать.** Сервер стоит дома, и в той же
  сети живёт подросток: раньше вход отвечал на неверный пароль сколько угодно
  раз подряд. Теперь пять ошибок прощаются, дальше пауза — от 30 секунд,
  вдвое больше с каждой новой ошибкой, до 15 минут. Неверный код второго
  фактора считается так же. Если вход заперт, страница скажет, сколько ждать.
- **Почта при входе — без учёта регистра и пробелов.** Телефон, начавший адрес
  с заглавной, больше не даёт «неверный адрес или пароль».
- **«Скопировать» работает на домашнем сервере.** Раньше кнопка не срабатывала
  по http вовсе — как раз для токена устройства.
- **Баланс у ребёнка обновляется сам**, пока страница открыта.
- Админку и страницу ребёнка можно добавить на главный экран телефона.

Обновление — так же, как ниже: `git pull` и
`docker compose -f deploy/docker-compose.yml up -d --build`.

## Что нового в 0.8.0 и как обновиться

Всё новое — на сервере; программы для Windows с 0.7.0 не менялись, кроме
номера версии, и переустанавливать их не нужно.

- **Цену задания называет сервер.** Раньше её присылал браузер ребёнка, и
  весь антифарм обходился одним запросом мимо страницы.
- **Задания «сделал сам» подтверждает родитель.** Таких в пакетах больше
  половины, и раньше каждое стоило одного нажатия кнопки.
- **Покупки с одобрением разбираются.** Раньше цена списывалась, а одобрить
  или отклонить покупку было нечем.
- **Повтор того же задания за месяц стоит меньше:** половину, потом четверть.
- **Правка правил больше не ломает белый список агента.** Раньше первое же
  сохранение лимитов стирало оттуда Проводник и сам агент. Стёртые списки
  обновление восстановит само; то, что вы добавляли туда вручную через API,
  стёрто безвозвратно — добавьте заново.
- **Новый интерфейс:** работает на телефоне, тёмная тема, настройки со вторым
  фактором, часовой пояс семьи, отвязка устройств.

Обновить сервер:

```bash
cd mykids
git pull
docker compose -f deploy/docker-compose.yml up -d --build
```

Изменения базы применятся сами при запуске. `SESSION_SECRET` в `deploy/.env`
больше не нужен — сервер его никогда не читал; оставленный, он ничему не мешает.

## Порядок установки

Полностью — в [`docs/SETUP.md`](https://github.com/vdoma88/mykids/blob/main/docs/SETUP.md).
Коротко:

1. Поднимите сервер, откройте `http://адрес-сервера:3000/`, заведите семью и
   ребёнка, задайте лимиты и курс обмена, **назначьте пакеты заданий**.
   Туда же, в «Одобрения», будут приходить задания, которые проверить машиной
   нельзя, — их подтверждаете вы.
2. Сделайте учётную запись ребёнка **обычной**, без прав администратора. Без
   этого всё остальное бессмысленно: ребёнок-администратор остановит службу.
3. Выдайте токен устройства на странице ребёнка.
4. Из учётной записи **родителя** запустите `MyKids-Setup-X.Y.Z.exe` и
   ответьте мастеру: адрес сервера, токен, учётная запись ребёнка. Дальше он
   всё сделает сам и скажет, запустилась ли служба.

   **Адрес нужен сетевой, а не `localhost`:** здесь это означает сам компьютер
   ребёнка. Мастер проверяет и не даст ошибиться.

   SmartScreen может предупредить о неизвестном издателе — подписи кода пока
   нет: «Подробнее» → «Выполнить в любом случае». Перед этим сверьте сумму с
   `sha256.txt`:

```
certutil -hashfile MyKids-Setup-X.Y.Z.exe SHA256
```

## Проверить, что всё видно

«Проверка MyKids» из меню «Пуск» запускается **из учётной записи ребёнка** и
открывает окно с четырьмя кнопками. Он спрашивает у Windows ровно то же, что
спрашивает агент, и сам говорит, что из этого работает: активное окно, рост
времени простоя, состояние экрана, номер сессии, состояние службы, права
запуска. Отдельными кнопками показываются полоса предупреждения и закрытый
экран — увидеть их может только человек, и про них он спрашивает прямо.

Отчёт копируется в буфер обмена одной кнопкой и параллельно пишется в
`%TEMP%\mykids-check.log`.

## Удаление

«Параметры» → «Приложения» → MyKids или «Удалить MyKids» в меню «Пуск».
Деинсталлятор снимает службу и закрывает помощника в сессии ребёнка. Каталог
`C:\ProgramData\MyKids` по умолчанию остаётся — в нём привязка и ещё не
отправленный учёт; удалить и его можно галочкой. После удаления отвяжите
устройство в админке, во вкладке «Устройства».

## Как это работает

Два процесса. Служба под `LocalSystem` считает время и принимает решения —
остановить её из своей учётной записи ребёнок не может. Помощник в сессии
ребёнка смотрит, какое окно активно, и рисует экран; запускает и
перезапускает его сама служба.

Помощнику не доверяют: он работает с правами ребёнка. Его молчание дольше
полуминуты считается расходом, а не отдыхом. Ложь о простое ловится на
противоречии — без ввода активное окно не переключается. Текст на экране
готовит служба, чтобы подменённый помощник не написал ребёнку «всё в порядке,
играй дальше».

О блокировке экрана служба больше не спрашивает помощника вовсе: она
спрашивает Windows сама, и этот ответ главнее в обе стороны. Заявленная
блокировка, которой нет, отменяется с первого же расхождения — а заявить её и
замереть на одном окне было самой выгодной ложью из возможных: противоречия
нет, ловить не на чем, время не списывается никогда. Настоящая блокировка,
наоборот, засчитывается теперь и тогда, когда помощник молчит: ребёнок,
заблокировавший экран и ушедший, больше не платит за те полминуты, пока
помощник перезапускается.

## Что видит подросток

В трее всегда виден остаток времени. Наведя курсор — «MyKids · Осталось
47 минут»; щёлкнув — меню с остатком, кредитами и ссылкой на задания:

```
Осталось 47 минут
Кредитов: 240
─────────────────
Задания и магазин
```

Это не украшение. Раньше агент был невидим до самого конца: сначала ничего,
потом полоса за несколько минут, потом закрытый экран. Для подростка это
выглядит как слежка, которая вдруг вмешалась, — а договаривались о правиле.
Правило, которое нельзя посмотреть, ничем не отличается от произвола.

Пункта «Выход» в меню нет и не будет: помощник — наблюдатель, и предлагать
закрыть его одним щелчком значило бы самим показать способ получить
бесплатное время.

За несколько минут до конца внизу справа появляется полоса — экран она не
перекрывает:

```
Осталось 5 минут
Сохранись.
```

Когда время кончилось:

```
Время на сегодня кончилось
Кредитов: 240 — это ещё 2 часа.
Завтра будет 1 час 30 минут.

Задания и магазин: http://адрес-сервера:3000/child
```

Никаких восклицательных знаков и уменьшительных слов: подростку они читаются
как разговор свысока. Это проверяется тестом, а не обещанием.

## За угаданное кредитов нет

Пакет из десяти заданий с четырьмя вариантами ответа можно прокликать наугад
за полминуты: четверть попаданий случайна. Теперь сервер смотрит, с какой
скоростью приходят ответы, — промежутки между ними он штампует сам, и
подделать их нельзя, не замедлившись на самом деле.

Одна быстрая попытка ничего не значит: кто знает ответ, отвечает быстро, и это
цель, а не нарушение. Несколько подряд — уже способ решения, и тогда ребёнок
видит:

```
Кредиты начисляются за решённое, а не за угаданное:
последние 3 ответа пришли быстрее чем за 4 с.
Реши это задание не торопясь — оно зачтётся.
```

Уже начисленное не отнимается: забирать кредиты задним числом значило бы
учить, что правила меняются.

Там же и вторая половина: то же задание, решённое повторно за тот же месяц,
стоит половины, на третий раз — четверти, и ниже не падает. Иначе выгоднее
всего было бы раз за разом решать одни и те же несколько заданий, которые уже
знаешь наизусть, — то есть система платила бы за то, чтобы ничему не учиться.

Задание, к которому вернулись через месяц, снова стоит полной награды: возврат
после долгого перерыва — самое полезное повторение из возможных.

## Цену задания называет сервер

Всё это держалось на честном слове до тех пор, пока ответы проверял браузер.
Страница ребёнка присылала серверу готовую оценку и вместе с ней — цену
задания и суточный потолок пакета. То есть ребёнок называл себе цену сам, и
обойти разом и потолки, и темп, и затухание за повторы можно было одним
запросом мимо страницы.

Теперь уходит только сам ответ. Проверяет его сервер, по своему экземпляру
пакета — там же лежат и правильный ответ, и цена, и потолок. Это то же
правило, по которому служба перестала спрашивать помощника о блокировке
экрана: смотреть не на то, что говорят, а на то, что видно самому.

## Что подтверждает родитель

Часть заданий машиной не проверить вовсе: «договориться о трёх правилах»,
«прибраться в комнате», «позвонить бабушке». Таких в пакетах больше половины,
и раньше каждое из них стоило одного нажатия «готово».

Теперь они попадают в «Одобрения» у родителя. Ребёнок видит «отправлено
родителю», кредиты приходят после подтверждения — по цене из пакета и по
сегодняшним потолкам. Подтверждение снимает только то условие, которое сервер
проверить не мог; оно не обходит ни дневной предел, ни cooldown. Если предел
на сегодня уже выбран, задание остаётся в очереди до завтра, а не закрывается
нулём: работа сделана, и заплатить за неё надо.

Там же — покупки с одобрением. Раньше это был тупик: цена списывалась сразу, а
одобрить или отклонить покупку было нечем, и ребёнок платил за то, чего не
получал. Теперь одобрение выдаёт награду, а отказ возвращает кредиты целиком.

## Новый интерфейс

Админка и страница ребёнка переделаны целиком: работают на телефоне, есть
тёмная тема, у страницы ребёнка — вкладки вместо ленты на несколько экранов.
Появились настройки со вторым фактором (раньше интерфейс напоминал, что он
выключен, а включить его было негде), отвязка устройства, выбор часового пояса
и выключение товара. Задания у ребёнка наконец оформлены: раньше таблица
Шульте не складывалась в сетку, а варианты ответа сливались в сплошной текст.

## Чего пока нет

- **Android-агента.** Только Windows.
- **Окна заданий в самом агенте.** Задания открываются в браузере — он в
  белом списке, поэтому открыть их можно и с закрытого экрана, и с другого
  устройства по тому же адресу `/child`.
- **Подписи кода.** SmartScreen будет ругаться на установщик: это ожидаемо,
  сертификат для подписи надо покупать.
- **Защиты от ребёнка с правами администратора.** Её и не будет: учётная
  запись обязана быть обычной.

## Честно о проверках

Ядро агента, протокол, учёт и решения сторожа покрыты тестами и проверяются
живым запуском двух настоящих процессов на каждый коммит. Сервер, админка и
интерфейс ребёнка проходят сквозной тест в браузере: родитель заводит ребёнка,
назначает пакеты, выдаёт токен; ребёнок решает задание, получает кредиты и
меняет их на время; задание с подтверждением уходит в очередь, родитель
подтверждает его в админке, и кредиты приходят.

Слой Win32 — оверлей, активное окно, запуск процесса в сессии — собирается и
проходит `vet`, но **на настоящей Windows не запускался**. Поэтому в релизе и
появилось окно проверки: начните с него, потом `status` и `watch`, и только
потом отдавайте агенту право закрывать экран.

Установщик собирается makensis с флагом «предупреждение — ошибка» на каждый
коммит и проверен разбором готового файла: три программы, иконка и
деинсталлятор на месте. Всё, что он решает, — что считать неверным адресом,
как понять ответ сервера на токен, кого предлагать учётной записью ребёнка, —
вынесено в `mykids-setup.exe` и покрыто тестами, включая ответы сервера: принят,
отозван, чужая программа по этому адресу, сервер молчит. Мастер только
показывает его отчёт. Запустить сам мастер здесь негде — Wine в окружении
сборки не стартует, — поэтому первую установку на настоящей Windows стоит
сделать, держа под рукой `%TEMP%\mykids-setup.log`.

Прежнее окно установки под Wine падало после первого нажатия: исключение на
стеке горутины Go, которое Wine доставить отказывается. Мастер вызывает
`mykids-setup.exe` без окна, поэтому этот путь его не касается. Само окно
осталось — двойной щелчок по `mykids-setup.exe` открывает его, как раньше.

Само окно проверки прогонялось под Wine: окно открывается, кнопки работают,
все шесть проверок отвечают осмысленно — так нашлись и были исправлены две
ошибки (наложение кнопок друг на друга и опрос сессии привилегией, которой у
ребёнка нет). Но Wine — не Windows, и под ним же обнаружилось падение при
нагрузке, которое воспроизводится и на пустой оконной программе на Go, то есть
относится к самому Wine. Проверить, ведёт ли себя так настоящая Windows,
отсюда нечем. Если окно закроется само — в `%TEMP%\mykids-check.log` останется
всё, что оно успело написать; пришлите этот файл.
