# @mykids/admin-ui

Интерфейс родителя и интерфейс ребёнка — одна сборка, два раздела.

```bash
npm run dev:admin        # http://localhost:5174, API проксируется на :3000
npm run build -w @mykids/admin-ui
node server/admin-ui/e2e.mjs   # сквозной тест в Chromium
```

В бою сборка отдаётся самим API с того же адреса: родитель открывает
`http://адрес-сервера:3000/`, ребёнок — `/child`. Два адреса вместо одного —
это ровно та инструкция, на которой домашнее развёртывание и заканчивается.
Путь к собранной сборке сервер берёт относительно себя; переопределяется
`MYKIDS_WEB_ROOT`. Порт 5174 остаётся только для разработки, где нужен
горячий перезапуск.

## Разделы

| Путь | Доступ | Что там |
|---|---|---|
| `/children` | сессия родителя | Карточки детей: баланс, связь с устройствами |
| `/children/:id` | сессия родителя | Обзор: события вмешательства, корректировка, последние операции |
| `/children/:id/rules` | сессия родителя | Лимиты по дням, часовой пояс, расписание, экономика, проверка курса |
| `/children/:id/packs` | сессия родителя | Назначение пакетов заданий |
| `/children/:id/devices` | сессия родителя | Устройства, выдача и отзыв токенов |
| `/children/:id/ledger` | сессия родителя | Журнал операций целиком |
| `/store` | сессия родителя | Товары: добавить, скрыть от ребёнка |
| `/approvals` | сессия родителя | Задания и покупки, ждущие решения |
| `/settings` | сессия родителя | Второй фактор, второй взрослый, тема |
| `/child` | токен устройства | Задания; `?s=shop` — обмен и магазин, `?s=rules` — правила |

Разделы ребёнка — параметром, а не путём: всё, что глубже `/child/`, сервер
считает запросами к API и требует токен устройства. Обновив страницу на
`/child/shop`, ребёнок получал бы 401 вместо магазина.

## Устройство

```
src/
  styles/     токены (светлая и тёмная тема), база, компоненты, раскладка
  ui/         Icon, kit (карточки, поля, вкладки, переключатели…), Toast, Async
  lib/        format (числа и даты по-русски), labels (подписи), theme
  layout/     Shell: боковое меню на широком экране, нижнее — на телефоне
  pages/      страницы родителя; child/ — вкладки страницы ребёнка
  kid/        интерфейс ребёнка
```

Стили самих заданий живут в `packages/task-runner/src/ui/runner.css` и
подключаются и здесь, и на странице локального прогона: одна копия на обоих.
Раньше интерфейс ребёнка рисовал задания вовсе без стилей — таблица Шульте не
складывалась в сетку, варианты ответа сливались в сплошной текст.

## Решения

**Ответ проверяет сервер.** Страница отправляет только сам ответ; правильный
ответ, цену задания и потолки сервер читает из своего экземпляра пакета.
Показывается его вердикт, а не свой: две оценки на одно задание — две версии
правды.

**Результат задания остаётся рядом с заданием.** После ответа задание не
подменяется следующим мгновенно: ребёнок видит, к чему относится «Не то», и
идёт дальше сам.

**Оформление без внешних ресурсов.** Системные шрифты, иконки — свои контуры
в коде. Сервер стоит дома и может жить без интернета; страница, ждущая шрифт с
чужого сервера, рисуется в таком доме пустыми прямоугольниками.

**Тема — как в системе, но выбор помнится.** Светлая и тёмная — одни и те же
токены с разными значениями; переключатель в меню и в настройках.

**Необратимое — в два нажатия, без модальных окон.** «Отвязать устройство»
спрашивает «Точно?» на месте той же кнопки: окно поверх перекрыло бы то, о чём
спрашивают.

**Числовое поле можно очистить.** Раньше пустое поле тут же становилось нулём,
и поменять «60» на «90» мешал ведущий ноль.

**Несохранённые правила видны.** Правка правил поднимает панель «Есть
несохранённые изменения»; уходя со страницы, браузер спросит.

**Симулятор курса рядом с экономикой.** Курс обмена невозможно настроить
наугад — нужно видеть, во что превращается дневной заработок. Считает теми же
функциями `@mykids/domain`, что и сервер.

**Ребёнку показываются его правила, а не только баланс.** Лимит на сегодня —
по часовому поясу семьи, а не устройства, как и сутки на сервере. Скрытая
механика в 11-13 лет воспринимается как несправедливость и провоцирует искать
обход вместо игры по правилам. Тексты — без восклицательных знаков и
уменьшительных слов: подростку они читаются как разговор свысока.

**Сообщение о результате строится по ответу сервера.** Обмен урезается до
доступного: запросил 100 минут, получил 10 — интерфейс обязан сказать именно это.

**Токен родителя и токен устройства хранятся раздельно.** Админка и интерфейс
ребёнка могут быть открыты на одной машине, путать их доступы нельзя.

**Запрос не уходит, пока нечем авторизоваться.** Иначе первый 401 прилетает
раньше, чем ребёнок успел ввести токен, и стирает только что введённое.

## Что проверяет сквозной тест

Поднимает API и собранную статику и проходит оба пути целиком. Родитель:
регистрация, первый ребёнок, правила на своей вкладке с проверкой курса, правка
и перечитывание после перезагрузки, корректировка с причиной, выдача токена,
назначение пакетов, товар в магазине. Ребёнок: баланс, правила, обмен, покупка,
урезанный обмен, отказ при нулевом балансе, перезагрузка раздела, задание с
результатом. Затем очередь одобрений: задание с подтверждением родителя — и
покупка на одобрение, которую родитель отклоняет и кредиты возвращаются.
