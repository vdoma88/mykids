# Админка родителя

Веб-приложение, отдаётся сервером. Единственная точка управления всей системой.

## Роли

| Роль | Права |
|---|---|
| `owner` | Всё, включая удаление семьи, ключи подписи, привязку устройств |
| `parent` | Политики, экономика, магазин, контент, одобрения, корректировки баланса |
| `viewer` | Только чтение отчётов (напр. второй родитель, бабушка) |
| `child` | Отдельный интерфейс: свой баланс, задания, магазин, история. **Не админка** |

Аутентификация: пароль + TOTP. Никаких PIN по умолчанию в коде — прямая ошибка CST,
которую не повторяем.

## Страницы

### 1. Дашборд
По каждому ребёнку на сегодня: потрачено / осталось / заработано кредитов, топ-5 приложений,
статус устройств (онлайн / молчит N часов), непрочитанные tamper-события, очередь одобрений.

### 2. Дети и устройства
- Профили детей: имя, возраст, аватар
- Привязка устройства: QR-код с одноразовым токеном
- По устройству: платформа, версия агента, последний контакт, состояние разрешений
  (для Android — выданы ли Usage Access, overlay, отключена ли оптимизация батареи)
- Кнопка «отвязать» с инвалидацией токена

### 3. Политики
- Дневные лимиты по дням недели
- `carryOverMaxMinutes` — перенос неистраченного
- Временные окна: школа, отбой, «только задания»
- Категории приложений: `always_allowed` / `metered` / `educational` / `blocked`.
  Список приложений подтягивается с устройства, родитель раскладывает по категориям
- Реакция на tamper: уведомление / списание минут / блокировка до разбора

### 4. Экономика
- Курс `creditsPerMinute`
- `maxConvertedMinutesPerDay` — потолок конвертации
- `minCreditsToConvert`
- **Симулятор**: «если ребёнок решит N заданий, он получит X минут» — чтобы настраивать
  курс осознанно, а не наугад. Самая полезная страница на старте.

### 5. Магазин
CRUD товаров: название, иконка, цена, эффект, лимиты, нужно ли одобрение.
Отдельная вкладка — очередь ожидающих одобрения покупок.

### 6. Контент
- Список установленных пакетов: предмет, версия, кол-во заданий, статус подписи
- Загрузка `.mkpack` / подтягивание из git
- Назначение пакетов детям, расписание («физика — по будням»)
- **Предпросмотр**: тот же Task Runner, что и на устройстве
- **Редактор заданий**: форма по типу задания, сразу пишет валидный JSON
- Очередь `parent_verified` — задания, ждущие подтверждения

### 7. Отчёты
- Экранное время: динамика по неделям, разбивка по приложениям и категориям
- Учёба: пройдено заданий, точность по предметам и темам, слабые темы
- Психологический профиль: динамика по `dimension` из `likert` — **как тренд, а не оценка**
- Экспорт CSV

### 8. Журнал (ledger)
Полный аудит всех начислений и списаний с фильтрами. Ручная корректировка баланса —
только с обязательным комментарием, попадает в тот же журнал.

### 9. Настройки
Смена пароля, TOTP, ключи подписи пакетов, резервное копирование и восстановление,
обновление агентов, язык.

## Интерфейс ребёнка

Отдельный, упрощённый, доступен на устройстве и в браузере:
баланс минут и кредитов, доступные задания, магазин, история за неделю,
**и текущие правила в явном виде**.

Ребёнок должен видеть, по каким правилам живёт система. Скрытая механика в 11-13 лет
воспринимается как несправедливость и провоцирует поиск обхода вместо игры по правилам.
